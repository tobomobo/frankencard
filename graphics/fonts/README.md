
# Fonts for Q1

This directory may contain font files from Font Awesome.

We cannot re-distribute the OTF files themselves due to their license.

However, once we render and build the compressed graphics file that we need,
the font is not required anymore.

compress.py wants 'Font Awesome 6 Sharp-Regular-400.otf' (Pro, costs money) but
falls back to 'Font Awesome 6 Free-Solid-900.otf', which has the few glyphs we
use (battery, plug) at the same codepoints. Get it from the free desktop
download at <https://fontawesome.com/download> (SIL OFL) and drop it in here.

Iosveka is open and can be re-distributed here.
